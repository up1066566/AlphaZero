> **Status:** 🚧 *Under Active Development*

## 📌 Overview

This repository contains the source code for my Master of Engineer Thesis. The project focuses on the **AlphaZero family of algorithms**, exploring reinforcement learning architectures, Monte Carlo Tree Search (MCTS), deep neural network integration and quantum enhacements for board game strategies.

The repository is currently under construction as part of ongoing research and implementation.
